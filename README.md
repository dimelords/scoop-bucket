# Scoop bucket for dimelords

[Scoop](https://scoop.sh) bucket for dimelords projects on Windows.

## Installation

```powershell
scoop bucket add dimelords https://github.com/dimelords/scoop-bucket
scoop install huddle-mcp
```

## What is here

| | |
| --- | --- |
| **huddle-mcp** | The client for [huddle](https://github.com/dimelords/huddle): the hooks the Huddle pane runs in Claude Code (in Git Bash), the channel bridge and image uploads. |

The manifests here are written by GoReleaser when each project releases, and
the zips they download come from that project's own release, so Scoop needs no
credentials. Edit them in the project, not here.
